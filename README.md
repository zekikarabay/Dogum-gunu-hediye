# Doğum Günü Hediyesi 🎉

Bu depo, arkadaşlar için **mobil uyumlu tek butonlu bir doğum günü sürprizi** sitesini içerir.  

## Özellikler

- Ortada büyük yuvarlak **BAS butonu**  
- Butona basınca:  
  - **Müzik çalıyor** (`1.mp3`) ve bitince otomatik tekrar başa dönüyor  
  - **Konfeti sonsuza kadar uçuyor**  
  - **“Doğum Günün Kutlu Olsun!”** mesajı çıkıyor  
- Altta imza: **by Zeki Karabay**  
- **Mobil uyumlu**: Telefon, tablet ve bilgisayarda düzgün çalışır
